## 一个黑五价是不是真便宜，用三个条件筛

同内存、同周期、算上续费。三个条件缺一个，比出来的结论就是错的。

**同内存**：4 GB 的黑五价和 1 GB 的常规价比，比出来的是配置差，不是折扣。
**同周期**：$6.49/月的前提是一次付 24 个月，你按月付拿不到这个价，拿月价去和年付价比也没意义。
**算续费**：首期便宜、续费翻倍是这轮促销的常见结构，第二年的账单才是你真正要付的钱。

用法很直接：看到任何“黑五特价”，先找到它的内存档，再看它是不是同一计费周期，最后把续费价加进去算第二年。三步走完还比表里的数字低，那才是真便宜。
